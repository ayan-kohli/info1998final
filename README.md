# Rent Climate Change Model: Info 1998 Final Project with Arnab Ghosh (ag2583)

Explores how climate vulnerability affects U.S. county rent increases by merging **CVI** (climate risk) and **ZORI** (rent) datasets \
Features include a **Composite Vulnerability Score**, **Affordability**, and **Change in Affordability** \
Models (Gradient Boosting, Random Forest) generate a **Livability Score** for county-level classification

## Run
Open and run `final.ipynb` to reproduce preprocessing, feature engineering, and modeling.
